# Verify a claimed number against the artifact that produced it

slug: vr.verify-number

## Description
Papers, reports and dashboards cite numbers. Those numbers came from somewhere — a data file, a
log, a script's output. This standard covers tracing a claimed value back to the artifact that
produced it, and recognising the three ways the trace fails: the artifact says something else, the
artifact does not exist, or the artifact says the same thing because it was written from the
claim. A citation is not a measurement.

---
## Assessment Requirements
In order to fully cover this standard, a performance must be recording for each of the following objectives:

0. Locate the artifact behind a cited number, and state its path and modification date
1. Compare the cited value to the artifact value at full precision, not at the precision quoted
2. Identify the estimator the artifact used, and confirm the citing text names the same one
3. Recognise a citation whose only source is another citation, and follow it to a primary or declare that none exists
4. Detect a number that falls outside its own stated confidence interval
5. Detect a caveat whose numbers were superseded by a later correction to the text it caveats
6. Distinguish "the artifact disagrees" from "the artifact is missing" from "the artifact was generated from the claim"
