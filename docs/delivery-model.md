# Three channels, and the rule that allocates between them

**Status: `PROPOSAL`, 2026-09-09.** Written after Thomas opened up continuing work, the Multiverse
workbook/reference component, and the campus agents — *"we can get creative here, they haven't
imposed any real constraints."*

This is the answer to the three overflows, and it is not a set of cuts.

---

## The rule

We already know which stages an agent can carry. It is [the pipeline's](../courses/vibe-research/the-pipeline.md)
central finding, and the course's whole thesis:

> **Your agent is strongest where the work is mechanical and weakest where it is decisive.**
> Judgment stages: **1 question · 3 design · 7 gate.** Mechanical: **2 survey · 5 execute ·
> 6 analyse · 8 ship.**

So allocate class time the same way:

> ## **The room gets the stages an agent is worst at. Everything an agent can carry, an agent carries.**

That is not a compromise to save minutes. **It is the course teaching its own thesis by being
built out of it.** A four-hour room spent on lit-review mechanics is a room contradicting its
own syllabus.

---

## The three channels

| channel | mode | carries | why there |
|---|---|---|---|
| **Workbook** | async, reference, any time | definitions, worked examples, templates, mechanical how-to | Reference material read once at speed beats reference material narrated to ten people at the pace of the slowest |
| **Campus agents** | async, interactive, between sessions | background delivery, project help, **gate-sparring**, the between-session partner | An agent is *good* at this, and it is available at 11pm on a Tuesday when the facilitator is not |
| **Live session** | synchronous, 4h, capped at 8 | judgment moves, pairing, the seeded reveals, the defence | Only what actually needs a room |

### What moves to the workbook, immediately

- **The glossary.** `AUROC`, `FWL`/residualisation, permutation null, *p*-floor, alpha, estimator,
  power, confidence interval. All used across sessions 2–3, **none defined anywhere**, and the
  audit's stated novice drop-out point is a block that uses four of them at once. This is the
  single highest-value thing the workbook can carry and it costs zero session minutes.
- **"Choosing a test."** Currently a real hole — no pipeline stage covers it, and session 2 hour 3
  asks students to run *"their planned test"* on noise. A workbook chapter plus an agent to work
  it through is a better teacher than an hour of lecture would have been.
- **Mechanical how-to** for stages 2, 5, 6, 8: running a lit review loop, provenance stamping,
  the staleness hook, packaging a repo so a stranger can run it.
- **Every worked case we currently narrate.** Students read them before the session; the room
  spends its minutes on what the case is *for*.

### What the campus agents take

- **The gate-sparring companion.** It is currently a spec, not a build
  (`docs/between-sessions-and-tone.md`), and **two sessions assign homework against it.** A campus
  agent with the right brief is that companion, and it exists today.
- **Between-session project help** — running the pilot, debugging the harness, the parts where
  being stuck alone at 11pm is what actually kills momentum.
- **Background delivery** for anyone arriving thin on a prerequisite.

## The consequence: a two-track target, which resolves the blocking decision

The [artifact-chain problem](./audit-2026-09-09.md) was that only *kills* survive a hand-off,
because every other artifact is attached to a target the next session abandons. Continuing work
dissolves it, and **without giving up either thing we wanted:**

| | **in-session target** | **carried pipeline** |
|---|---|---|
| what | rotates every session — `temperature=0`, option order, step-by-step, judge agreement | **one supplied target, chosen at session 1, carried all four** |
| bounded? | yes, by construction — an afternoon | yes, but built stage by stage across ~56 days |
| purpose | teach *this session's* judgment move, with a clean reveal | **be the pipeline they walk out owning** |
| lives | the room | continuing work, workbook, agent |

**Both original rationales survive.**

- *The target bank's:* session 1's lit review still can't kill session 2's in-session target,
  because they are different targets. Rotation is intact where it was needed.
- *Thomas's "the question is supplied":* the carried pipeline is **also supplied** — from the bank
  or the pre-made setups. Nobody burns class time defending a personal project.
- *The arc:* the walks-in chain becomes about the **carried pipeline**, which does not rotate. A
  design, a prereg, a pilot, a result, a limits section, a repo — each accumulates, each survives
  to the next session, and hour 4 of session 4 defends something real.

And it is exactly what Thomas asked for: *"the focus should be on getting them introduced to the
phases and have a pipeline at least significantly built out through the steps."* The in-session
targets introduce the phases. The carried pipeline is the thing that gets built out.

## What this does to the clocks

The four missing artifacts stop being missing, and none of them costs a session hour:

| artifact | was | becomes |
|---|---|---|
| **a design** | assumed by S2, scheduled nowhere | workbook template + pre-work; S2 opens with it drafted |
| **a chosen test** | assumed by S2h3, taught nowhere | workbook chapter + agent; the room does the *noise run*, not the choosing |
| **the pilot** | one line of homework, required by all of S3 | continuing work between S2 and S3, agent-supported, **plus a supplied fallback dataset** |
| **a repository** | assumed by S4's handoff, asked for nowhere | accumulates from S1; workbook gives the structure |

Sessions 2 and 3 were the worst overflows (247 and 252 against 201) and **most of that was
regenerating what rotation threw away, plus teaching mechanics.** Both come back inside the
container without losing a single teaching beat — the beats move channel, they do not disappear.

## `OPEN` — what this needs before it is real

- **Does the Multiverse workbook platform exist and what can it hold?** Ask Liz. Everything above
  assumes text, templates and worked examples; if it also does exercises or checkpoints, more
  moves.
- **What can a campus agent actually be briefed to do**, and who writes the brief? The
  gate-sparring companion is the first and highest-value one.
- **The supplied fallback dataset** still does not exist and is now load-bearing for continuing
  work, not just for stragglers.
- **Assessment moves too.** If the pipeline is built in continuing work, the paired gated/ungated
  run — the course's headline assessment, currently scheduled in no session — is a **continuing-work
  deliverable**, which is where it always fitted better anyway.
